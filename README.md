# HealthKitBundle

Liveness and readiness endpoints with pluggable probes (Doctrine, Redis, Messenger queue depth, FrankenPHP) and a token-guarded Prometheus /metrics endpoint for Symfony apps.

> **Status: in development.** This package is being extracted from [Symfony Beacon](https://github.com/nowo-tech/symfony-beacon)
> (audit 2026-10-31, kit extraction plan). No stable release yet; the first tagged version will meet the nowo-tech
> bundle standards (tests, 100% coverage, demo, docs, security audit).

## Installation

```bash
composer require nowo-tech/health-kit-bundle
```
